# AOTS⁶ — EVIDENCIA FORENSE INMEDIATA

Toda afirmación histórica debe poder abrirse inmediatamente hasta su evidencia.

## Cadena obligatoria

NARRATIVA → AFIRMACIÓN ATÓMICA → FUENTE → SIGNATURA/IDENTIFICADOR → OBJETO → SHA-256 → LOCALIZADOR → EXTRACCIÓN → CORROBORACIÓN → ESTADO.

Una afirmación sin ruta de evidencia no puede presentarse como DOCUMENTADA.

## Registro atómico

Cada afirmación recibe `claim_id` y conserva: texto, sujeto, predicado, objeto, fecha, lugar, actor, acto, fuente primaria, archivo, signatura, URL, fecha de consulta, objeto digital, SHA-256, folio/página, transcripción, corroboración, estado epistemológico, operador y fecha de extracción.

## Estados

OBSERVADO · DOCUMENTADO · CORROBORADO · RECONSTRUIDO · INFERIDO · HIPÓTESIS · REFUTADO · NO-DETERMINADO.

## Prohibiciones de inferencia

HIPÓTESIS → HECHO
SIMILITUD → CAUSALIDAD
APELLIDO → PROPIEDAD
CONTINUIDAD NOMINAL → CONTINUIDAD INSTITUCIONAL
HASH → VERDAD HISTÓRICA

## Reproducibilidad

Una tercera persona debe poder localizar la misma referencia, obtener el objeto cuando el acceso lo permita, calcular el mismo hash, localizar el mismo folio/página, repetir la transformación y obtener la misma afirmación. Si una etapa no puede repetirse, el estado debe indicar NO-REPRODUCIBLE o PARCIALMENTE-REPRODUCIBLE.

## Regla final

La narrativa no desaparece: se convierte en un grafo auditable donde cada afirmación apunta a una evidencia concreta y cada evidencia conserva su procedencia e integridad.
