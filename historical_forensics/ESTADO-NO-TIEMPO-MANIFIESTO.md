# MANIFIESTO OPERATIVO — ESTADO DE NO TIEMPO

El tiempo histórico no se recupera borrando el presente ni corrigiendo una versión mediante otra. Se preserva el conjunto de estados y se hace explícita la relación entre ellos.

**Regla:** no se pide a la memoria que crea; se le exige que muestre el objeto, su procedencia y la transformación que produjo la lectura.

Una fuente cerrada, una fuente incompleta, una fuente catalogada sin imagen y una fuente digitalizada con hash verificable son estados distintos. Ninguno se eleva artificialmente al siguiente.

Cadena reproducible:

repositorio → referencia → objeto → bytes → SHA-256 → localizador → literal → derivación → corroboración

La ausencia de una pieza no se oculta: se convierte en un estado explícito que puede ser completado, refutado o corregido.

El objetivo operativo no es controlar la historia. Es impedir que una afirmación quede sin rastro hacia aquello de lo que afirma proceder.
