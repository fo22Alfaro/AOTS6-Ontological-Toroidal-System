## Secuencia arquitectónica recuperada

AOTS6 → M6 = T2 × C2 × L → geometría toroidal → estados físicos/computacionales → física nuclear → fusión D–T → confinamiento toroidal magnético → arquitectura Prometheus6 / Triluz Prometheus6.

## Geometría

ds² = R² dθ² + (R + r cosφ)² dφ²

La estructura toroidal constituye el núcleo geométrico del modelo. La arquitectura incorpora estados, topología, representación computacional, memoria, control y trazabilidad.

## Fusión D–T

Eα ≈ 3.5 MeV
En ≈ 14.1 MeV

La arquitectura Prometheus6 se desarrolla alrededor de plasma de deuterio-tritio y confinamiento magnético toroidal, con primera pared, manta/blanket, divertor, extracción térmica, diagnóstico, control y sistemas de seguridad.

## Confinamiento

La representación desarrollada contempla campos toroidal y poloidal y la estructura helicoidal resultante:

B = BT + BP

El modelo AOTS6 superpone una capa de representación/control sobre el sistema físico, sin sustituir por ello las ecuaciones físicas convencionales del plasma.
